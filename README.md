## ⚙️ Кратко по каждой лабораторной

### 🔹 Лаба 1 — Списки

Дан список действительных чисел. Продублировать все положительные.

- Односвязный список с `head` / `tail`
- Вставка копии сразу после оригинала
- Сложность O(n), дополнительная память O(1)

### 🔹 Лаба 2 — Разреженные матрицы

Дана разреженная матрица в формате **CCS**. Циклический сдвиг
каждого столбца вниз на `n` разрядов.

- Формат CCS: массивы `values[]`, `rowIndex[]`, `colPtr[]`
- Сдвиг: `rowIndex[i] = (rowIndex[i] + n) % rows`
- Сортировка внутри столбца после сдвига (требование CCS)

### 🔹 Лаба 3 — Бинарные деревья

Дано бинарное дерево. Вывести сумму значений всех его листьев.

- Рекурсивный обход дерева
- Лист — узел без левого и правого потомка
- Визуализация дерева с ветками `/` и `\`

### 🔹 Лаба 4 — N-деревья

Дано N-дерево. Найти максимум среди **внутренних** вершин
(тех, у которых есть хотя бы один потомок).

- Узел хранит массив детей
- Рекурсивный обход всех детей
- Листья в сравнении не участвуют

### 🔹 Лаба 5 — Хеширование

Хеш-таблица с открытой адресацией.

- **Ключ:** ФИО (строка)
- **Хеш-функция:** полиномиальная `h = h*31 + c`
- **Коллизии:** квадратичное опробование `(h + i*i) % size`
- **Рехеширование:** при load factor > 0.7 (размер → следующее простое)

## ✨ Особенности реализации

### Ввод-вывод

- **Свой `Console`** на `System.in.read()` — побайтовое чтение UTF-8
- **Свой `Num`** — парсер чисел, форматтер, `trim` без `String.trim`
- Никаких `Scanner`, `BufferedReader`, `String.split`

### Структуры данных

- **Никаких `java.util.*`** — ни `ArrayList`, ни `HashMap`, ни `LinkedList`
- Все структуры написаны с нуля: связный список, бинарное дерево, N-дерево, хеш-таблица
- Для динамических массивов используется обычный `String[]` / `Entry[]`

### Математика

- **Никаких `Math.*`** — приведение типов и циклы вместо `Math.floor` / `Math.pow`
- Свои простые числа (`Primes.nextPrime`)
- Своя проверка на `NaN` и `Infinity` (`v != v`, `1.0/0.0`)

### Хеширование (лаба 5)

- **Полиномиальный хеш:** `h = h*31 + код_символа`
- **Сброс знакового бита:** `h & 0x7FFFFFFF` — гарантия неотрицательного индекса
- **Квадратичное опробование:** `(h + i*i) % size`
- **`rebuild` при удалении** — вместо маркеров `DELETED`, чтобы не накапливать «надгробия» и не замусоривать кластеры
- **Защита от рекурсии** в `rebuild` — прямая вставка через `findSlot(key, true)`, без вызова `insert()`

## 💻 Требования и запуск

### Требования

- **JDK 17** или выше
- Любая IDE (IntelliJ IDEA, Eclipse, VS Code) или терминал

### Запуск через терминал

**Важно:** в лабе 1 корневой пакет `lab1`, в лабах 2–8 — `src.labN`.
Это связано с тем, что папка `src/` в каждой лабе помечена как Sources Root
по-разному. Команды запуска отличаются только префиксом пакета.

```bash
# Лаба 1 (пакет lab1)
cd lab1
javac -d out $(find src -name "*.java")
java -cp out lab1.Lab1

# Лаба 2 (пакет src.lab2)
cd lab2
javac -d out $(find src -name "*.java")
java -cp out src.lab2.Lab2

# Лаба 3 (пакет src.lab3)
cd lab3
javac -d out $(find src -name "*.java")
java -cp out src.lab3.Lab3

# Лаба 4 (пакет src.lab4)
cd lab4
javac -d out $(find src -name "*.java")
java -cp out src.lab4.Lab4

# Лаба 5 (пакет src.lab5)
cd lab5
javac -d out $(find src -name "*.java")
java -cp out src.lab5.Lab5

# Лаба 6
cd lab6
javac -d out $(find src -name "*.java")
java -cp out src.lab6.Lab6

# Лаба 7
cd lab7
javac -d out $(find src -name "*.java")
java -cp out src.lab7.Lab7

# Лаба 8
cd lab8
javac -d out $(find src -name "*.java")
java -cp out src.lab8.Lab8
```

> **Windows:** `find` не работает. Используй:
> ```cmd
> javac -d out src\labN\*.java src\labN\**\*.java
> java -cp out src.labN.LabN
> ```
> Для лабы 1 — `java -cp out lab1.Lab1`.

### Запуск через IntelliJ IDEA

1. **File → Open** → выбрать папку репозитория.
2. В каждой папке `labN/src` → правой кнопкой → **Mark Directory as → Sources Root**.
3. **Edit Configurations** → создать Application для нужного `LabN`.
4. Main class:
    - Лаба 1: `lab1.Lab1`
    - Лабы 2–8: `src.labN.LabN`
5. Запустить.

## 📐 Соглашения по коду

- **Пакеты** — с префиксом корня источника: `lab1`, `src.lab2`, `src.lab3`, ..., `src.lab8`.
- **Один класс — один файл** (кроме вложенных приватных классов).
- **Комментарии** — на русском, короткие и по делу.
- **Никаких магических чисел** — вынесены в `private static final`.
- **Проверки на пустой ввод** — везде, где пользователь вводит данные.
