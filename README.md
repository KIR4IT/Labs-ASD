## ⚙️ Кратко по каждой лабораторной

### 🔹 Лаба 1 — Списки

Дан список действительных чисел. Продублировать все положительные.

- Односвязный список с `head` / `tail`
- Вставка копии сразу после оригинала
- Сложность O(n), дополнительная память O(1)

### 🔹 Лаба 2 — Разреженные матрицы

Дана разреженная матрица в формате **CCS**. Циклический сдвиг
каждого столбца вниз на `n` разрядов.

- Формат CCS: массивы `values[]`, `rowIndex[]`, `colPtr[]`
- Сдвиг: `rowIndex[i] = (rowIndex[i] + n) % rows`
- Сортировка внутри столбца после сдвига (требование CCS)

### 🔹 Лаба 3 — Бинарные деревья

Дано бинарное дерево. Вывести сумму значений всех его листьев.

- Рекурсивный обход дерева
- Лист — узел без левого и правого потомка
- Визуализация дерева с ветками `/` и `\`

### 🔹 Лаба 4 — N-деревья

Дано N-дерево. Найти максимум среди **внутренних** вершин
(тех, у которых есть хотя бы один потомок).

- Узел хранит массив детей
- Рекурсивный обход всех детей
- Листья в сравнении не участвуют

### 🔹 Лаба 5 — Хеширование

Хеш-таблица с открытой адресацией.

- **Ключ:** ФИО (строка)
- **Хеш-функция:** полиномиальная `h = h*31 + c`
- **Коллизии:** квадратичное опробование `(h + i*i) % size`
- **Рехеширование:** при load factor > 0.7 (размер → следующее простое)
- **Ручное рехеширование:** пункт меню для принудительного увеличения таблицы
- **Тестовые данные:** 5 ФИО для автозаполнения одним нажатием

### 🔹 Лаба 6 — Сортировки (QuickSort)

Дан массив чисел. Отсортировать числа в диапазоне `[N; K]`
с помощью **быстрой сортировки**.

- Свой динамический массив `DoubleArray` (без `ArrayList`)
- Быстрая сортировка с **3-way partition** (Dijkstra's Dutch National Flag)
- Числа в диапазоне сортируются **внутри исходного массива** — на своих позициях
- Числа вне диапазона **не трогаются**

## ✨ Особенности реализации

### Ввод-вывод

- **Свой `Console`** на `System.in.read()` — побайтовое чтение UTF-8
- **Свой `Num`** — парсер чисел, форматтер, `trim` без `String.trim`
- Никаких `Scanner`, `BufferedReader`, `String.split`

### Структуры данных

- **Никаких `java.util.*`** — ни `ArrayList`, ни `HashMap`, ни `LinkedList`
- Все структуры написаны с нуля: связный список, бинарное дерево, N-дерево, хеш-таблица, динамический массив
- Для хранения данных используется обычный массив примитивов (`double[]`, `Entry[]`)

### Математика

- **Никаких `Math.*`** — приведение типов и циклы вместо `Math.floor` / `Math.pow`
- Свои простые числа (`Primes.nextPrime`)
- Своя проверка на `NaN` и `Infinity` (`v != v`, `1.0/0.0`)

### Хеширование (лаба 5)

- **Полиномиальный хеш:** `h = h*31 + код_символа`
- **Сброс знакового бита:** `h & 0x7FFFFFFF` — гарантия неотрицательного индекса
- **Квадратичное опробование:** `(h + i*i) % size`
- **`rebuild` при удалении** — вместо маркеров `DELETED`, чтобы не накапливать «надгробия» и не замусоривать кластеры
- **Защита от рекурсии** в `rebuild` — прямая вставка через `findSlot(key, true)`, без вызова `insert()`
- **Ручное рехеширование** — пункт меню 5, увеличивает размер в 2 раза и пересобирает таблицу
- **Тестовые данные** — пункт меню 6, загружает 5 ФИО, пропуская уже существующие

### Сортировка (лаба 6)

- **Свой динамический массив** `DoubleArray` — расширяется вручную в 2 раза
- **QuickSort с 3-way partition** (Dutch National Flag):
   - pivot выбирается в середине
   - массив разбивается на три части: `< pivot`, `= pivot`, `> pivot`
   - **не падает на массивах с дубликатами** — в отличие от классической схемы Хоара
- **Сортировка чисел в диапазоне `[N; K]` в исходном массиве:**
   1. собираются индексы элементов, попадающих в `[N; K]`
   2. значения этих элементов сортируются
   3. отсортированные значения раскладываются обратно на те же позиции
   4. элементы вне диапазона остаются нетронутыми

### Лаба 6 — QuickSort

**Тест 1 — базовый случай: сортировка чисел в диапазоне значений**

```
=== Лаба 6: быстрая сортировка чисел в диапазоне [N; K] ===
Введите числа через пробел или запятую.

Введите числа: 5 3 8 1 9 2

Исходный массив:
  [5, 3, 8, 1, 9, 2]  (6 эл.)

Введите N (нижняя граница): 2
Введите K (верхняя граница): 7

Числа в диапазоне [2; 7]:
  [5, 3, 2]  (3 эл.)

Массив после сортировки чисел в диапазоне:
  [2, 3, 8, 1, 9, 5]  (6 эл.)
```

**Что произошло:**
- В диапазон `[2; 7]` попали числа: `5` (индекс 0), `3` (индекс 1), `2` (индекс 5).
- Они отсортированы: `[2, 3, 5]`.
- Разложены обратно по позициям `0, 1, 5` → массив стал `[2, 3, 8, 1, 9, 5]`.
- Числа `8, 1, 9` **не тронуты** (они вне диапазона).

---

**Тест 2 — массив из одинаковых чисел (проверка 3-way partition):**

```
Введите числа: 5 5 5 5 5

Введите N: 5
Введите K: 5

Числа в диапазоне [5; 5]:
  [5, 5, 5, 5, 5]  (5 эл.)

Массив после сортировки чисел в диапазоне:
  [5, 5, 5, 5, 5]  (5 эл.)
```

**Что произошло:**
- Все числа равны `5`, все попадают в диапазон `[5; 5]`.
- Классическая схема Хоара на таком массиве **упала бы с `StackOverflowError`** — потому что pivot = 5, и обе части массива остаются того же размера.
- **3-way partition** собирает все равные pivot в середину (`lt..gt`), рекурсия идёт только на `< pivot` и `> pivot`. Обе части **пустые** → рекурсия завершается мгновенно.
- **Массив не меняется** (все элементы равны), но программа **не падает**.

**Тест 4 — пустой диапазон:**

```
Введите числа: 1 2 3

Введите N: 10
Введите K: 20

В диапазоне [10; 20] чисел нет.
```

**Что произошло:** ни одно число не попало в `[10; 20]` → сортировать нечего.

---

**Тест 5 — N > K (автоматический обмен границ):**

```
Введите числа: 5 3 8

Введите N: 8
Введите K: 3
  [i] N > K, границы поменяны местами.

Числа в диапазоне [3; 8]:
  [5, 3, 8]  (3 эл.)

Массив после сортировки чисел в диапазоне:
  [3, 5, 8]  (3 эл.)
```

**Что произошло:** пользователь ввёл `N = 8`, `K = 3`. Программа автоматически поменяла местами → диапазон стал `[3; 8]`. Все числа попали в диапазон → отсортировались в исходном массиве.

---

**Тест 6 — одно число:**

```
Введите числа: 42

Введите N: 40
Введите K: 50

Числа в диапазоне [40; 50]:
  [42]  (1 эл.)

Массив после сортировки чисел в диапазоне:
  [42]  (1 эл.)
```

**Что произошло:** одно число в диапазоне — сортировка тривиальна.

---

**Тест 7 — отрицательные числа:**

```
Введите числа: -5 3 -2 8 -1

Введите N: -5
Введите K: 0

Числа в диапазоне [-5; 0]:
  [-5, -2, -1]  (3 эл.)

Массив после сортировки чисел в диапазоне:
  [-5, -2, 3, 8, -1]  (5 эл.)
```

**Что произошло:** в диапазон `[-5; 0]` попали `-5`, `-2`, `-1`. Они отсортированы: `[-5, -2, -1]`. Разложены обратно по позициям. `3` и `8` — не тронуты.
